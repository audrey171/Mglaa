How it works

Two colors set the harmony. Their hex digits form a melody, and the weaving pattern moves it through the chord. The same colors and pattern produce the same sequence.

1. Color → chord

Each color becomes hue h, saturation s, and lightness l. Hue chooses the chord’s root; saturation chooses major or minor. Lightness sets how high the melody sits.

The two hues are blended around the color wheel, with more saturated colors carrying more weight:

H = atan2(Σ si sin hi, Σ si cos hi) mod 360°
S = (s0 + s1)/2,   L = (l0 + l1)/2

After rounding the blend to hex, each 30° hue sector moves the root one fifth. If the hues cancel, the first color’s hue is used:

r = 36 + (7⌊H/30⌋ mod 12)
I = [0, 3, 7, 10] if S < 0.3; otherwise [0, 4, 7, 11]
pad = [r, r + 7, r + I3, r + 12 + I1]

r is a MIDI note number; I lists semitone intervals for a minor or major seventh chord. The pad holds this harmony, and every melody note stays within it.

2. Hex → phrase

A hex code supplies six numbers from 0–15: #6D2A49 becomes [6, 13, 2, 10, 4, 9]. Each digit selects one of four chord tones. Lightness places it one, two, or three octaves above the root. For each color’s own root and intervals:

o = 12 + 12 round(2l)
aj = 0 if j mod 8 = 0; otherwise round(3dj mod 6/15)
qj = r + o + Iaⱼ

Each color first makes its own phrase. Every fourth step is kept; hex digits and saturation decide the remaining rests:

play at step j if j mod 4 = 0, or
[(d(j+3) mod 6 + 3(j mod 3)) mod 16]/16 ≤ 0.12 + 0.68s

The colors take alternating turns in a shared 16-step phrase. A second saturation-based test adds rests, and each note is fitted to the nearest shared-chord tone. More saturation generally allows more notes through.

This mapping is a composition rule made for mglaa, not an inherent relationship between color and pitch.

3. Pattern → melodic movement

The same draft drives image and sound. T assigns shafts (0–3) to columns; P lists the two lowered shafts in each row:

D(x, y) = 1[Tx ∈ Py]

A 1 displays the first color; a 0 displays the second. The shaft shifts the melody along the chord, with a wider harness pair adding one more step:

δt = Tt − 1 + 1[Pt,1 − Pt,0 > 1]
mt = Aclamp(b + δₜ, 0, |A| − 1)

A lists shared-chord notes from MIDI 45–81; b locates the nearest note to the color phrase. 1[condition] means 1 when true, 0 otherwise. The pattern changes the melody’s contour while keeping it in harmony.

4. Time → sound

Tempo stays at 84 BPM. Each half-beat adds one textile row; individual squares do not each trigger a note. The phrase repeats within a longer loop set by the opening window width.

Δt = 60/(84 × 2) ≈ 0.357 s
f(m) = 440 × 2(m − 69)/12 Hz
melody filter cutoff = 6500 − 5400z Hz

The final note m becomes a frequency. Softness z (0–1) lowers the melody’s filter cutoff and softens its attack. Pads and delay let notes overlap without changing the tempo.
