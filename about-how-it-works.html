How it works

The same palette and draft produce the same sequence. The mapping is a composition rule made for mglaa: colors choose a harmony, their hex digits make a phrase, and the weaving draft moves that phrase through the chord.

1. Two colors choose a chord

Each color is converted to hue h (0–360°), saturation s (0–1), and lightness l (0–1). Hue is averaged around a circle, weighted by saturation:

x = Σ si cos(hi),   y = Σ si sin(hi)
H = atan2(y, x) mod 360°
S = (s0 + s1)/2,   L = (l0 + l1)/2

The more saturated color has more influence. If the vectors cancel, the first color’s hue is used. The combined HSL color is rounded to an RGB hex color, then converted back to HSL for the chord calculation below.

k = ⌊H/30⌋
p = (7k) mod 12
r = 36 + p

Each 30° hue sector advances one fifth around the chromatic scale. Pitch class 0 is C, 1 is C♯, and so on. r is the root as a MIDI note number.

I = [0, 3, 7, 10]   if S < 0.3   (minor seventh)
I = [0, 4, 7, 11]   otherwise   (major seventh)
pad = [r, r + 7, r + I3, r + 12 + I1]

The pad holds this chord. The melody uses only its pitch classes, across several octaves, so the two stay in harmony.

2. Hex digits create notes and rests

A six-digit hex color becomes six integers d0…d5, from 0 to 15. For example, #6D2A49 becomes [6, 13, 2, 10, 4, 9]. Each color first makes its own 16-step phrase, using its individual root and chord intervals from the same hue rule.

o = 12 + 12 round(2l)
aj = 0   if j mod 8 = 0;   otherwise round(3dj mod 6/15)
qj = r + o + Iaⱼ

Lightness chooses the register: one, two, or three octaves above the individual root. The digit chooses a chord tone. Steps 0 and 8 return to the root tone. Every fourth step is kept; other steps are kept when:

[(d(j+3) mod 6 + 3(j mod 3)) mod 16]/16 ≤ 0.12 + 0.68s

Call the resulting ordered list of notes Ei for color i. In the shared phrase, the two colors alternate. At step t = 0…15, let i = t mod 2 and u = ⌊t/2⌋. The first turn of each color always sounds. Later turns sound when:

d(u+i) mod 6/15 ≤ 0.3 + 0.7si

The target is note (u + i) mod length(Ei) from that color’s list. It is fitted to the nearest note of the shared chord between MIDI 48 and 88. Greater saturation generally allows more notes through; lower saturation leaves more rests.

3. The weaving draft reshapes the phrase

Let Tx be the shaft assigned to column x, numbered 0–3 in the equations, and Py the pair of lowered shafts for row y. Both sequences repeat. The visible textile is:

D(x, y) = 1   if Tx ∈ Py;   otherwise 0

A 1 uses the first palette color; a 0 uses the second. The book’s threading and harness sequence create the motif. Each named draft uses one source treadling variation. Border threads and the fine tabby binding rows are omitted to keep the square proportions of the printed pattern diagrams.

The musical phrase reads these same two sequences at each sounding step n. Let A be the ascending list of shared-chord notes between MIDI 45 and 81, and b the index of the note in A nearest the target from the color phrase.

δn = Tn − 1 + 1[Pn,1 − Pn,0 > 1]
mn = Aclamp(b + δₙ, 0, length(A) − 1)

1[condition] adds one when the condition is true. The shaft shifts the melody along the chord; a wider harness pair adds another step. The index is clamped at the ends of the available range. Notes are slightly stronger when their shaft belongs to the lowered pair: the level is multiplied by 0.8, otherwise by 0.6. Higher notes are also softened. Instrument presets may shift the result down an octave without changing its chord membership.

4. Time and sound

Tempo stays at 84 beats per minute. Each step is half a beat, about 0.357 seconds:

Δt = 60/(84 × 2)
f(m) = 440 × 2(m − 69)/12 Hz

The 16-step color phrase repeats inside a longer loop whose length is set from the window width when the instrument opens. The threading and harness sequences run through their own repeats within it. Each step advances one textile row. The image and music share a draft, but a filled cell does not trigger a separate note.

Softness changes the sound rather than the notes or tempo. For softness z between 0 and 1, the sampled melody’s low-pass cutoff is 6500 − 5400z Hz. Attacks grow gentler as softness rises; pads sustain underneath, and a quiet filtered delay lets the melody overlap.
